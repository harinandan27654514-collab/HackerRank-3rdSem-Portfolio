## ⚡ Complexity Analysis

| Problem | Time | Space | Key Idea |
|---------|:----:|:-----:|----------|
| Compare the Triplets | `O(1)` | `O(1)` | Compare three fixed pairs |
| Diagonal Difference | `O(N)` | `O(1)` | Sum both diagonals in one pass |
| Dynamic Array | `O(N + Q)` | `O(N)` | Vector of vectors, index via XOR with `lastAnswer` |
| Sparse Arrays | `O(N + Q)` | `O(N)` | Hash map of string frequencies |
| Time Conversion | `O(1)` | `O(1)` | Parse hour and adjust for AM/PM |
